# APEX 26 Hospital ERP - User Guide

## Dashboard Overview
- Real-time Hospital Statistics
- Bed Occupancy Rate
- Revenue Overview
- Pending Admissions
- Quick Actions

## Patient Management

### Registering a New Patient
1. Navigate to Patient Registration
2. Fill in patient details
3. Validate contact information
4. Click Save
5. Patient ID will be auto-generated

### Searching Patients
1. Use Search bar on Patient Search page
2. Enter patient name, contact, or ID
3. View search results
4. Click on patient to view full details

## Admission & Discharge

### Patient Admission
1. Search and select patient
2. Choose department
3. Select available bed
4. Set admission date
5. Add notes (optional)
6. Save admission record

### Patient Discharge
1. Select admitted patient
2. Add discharge notes
3. Calculate final bill
4. Process discharge
5. Generate discharge summary

## Billing Process

### Creating a Bill
1. Open Billing Entry
2. Select patient/admission
3. Add services with quantities
4. System calculates total
5. Save bill

### Processing Payment
1. Open Bill Payment
2. Search bill by ID
3. Enter payment amount
4. Select payment mode
5. Generate receipt

## Reports

### Available Reports
- Daily Census Report
- Revenue Report
- Bed Occupancy Report
- Department-wise Analysis
- Financial Summary

### Generating Reports
1. Navigate to Reports section
2. Select report type
3. Set date range
4. Click Generate
5. Export as PDF/Excel
